#  Pokémon Data Analysis & Power BI Dashboard

An exploratory data analysis and interactive visualization project examining a dataset of **800+ Pokémon** across **13 attributes** (including types, combat statistics, generation, and legendary status). This project investigates Pokémon strength, rarity, and generational shifts in combat power.

---

##  Project Overview
This project transforms raw Pokémon data into actionable, interactive insights to uncover statistical patterns, attribute correlations, and design trends across generations. 

### **Key Highlights:**
- **Comprehensive Dataset:** Analyzed 800 Pokémon across 13 distinct features.
- **Interactive Visualizations:** Built dynamic Power BI dashboards to evaluate combat performance and attribute rarity.
- **Generational Insights:** Compared variations in `Attack` and `Special Attack` metrics across different generations.
- **Collaborative Execution:** Led a team effort to clean, model, structure, and visually present data-driven findings.

---

##  Tools & Technologies
- **Data Visualization:** Microsoft Power BI
- **Data Source:** [Pokémon Dataset (Google Drive)](https://drive.google.com/drive/folders/12bnmoB6DUldxIt2KEn1VLfIvpjfHUL2t?usp=sharing)
- **Collaboration & Management:** Team-based workflow for data cleaning, metric definition, and presentation design.
##  Key Findings & Objectives
1. **Strength & Rarity Analysis:** Explored the distribution of base stats (HP, Attack, Defense, Speed, etc.) to identify outliers and understand what makes a Pokémon statistically powerful.
2. **Generational Trends:** Investigated how base combat stats (specifically `Attack` vs. `Special Attack`) have evolved or shifted across different generations.
3. **Attribute Relationships:** Discovered underlying patterns and correlations between primary/secondary types, legendary status, and overall combat effectiveness.

*This project was developed for learning and portfolio purposes.*
